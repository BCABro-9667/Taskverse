# **App Name**: TaskMaster

## Core Features:

- Authentication: User authentication (login/register) to secure access to the application.
- Task Creation: Add a new task with assignee (dropdown with 'Add New Assignee' modal), due date, and notes.
- Task Display: Display tasks in two sections: 'Pending Tasks' (top) and 'Completed Tasks' (bottom). Task items show task name, date, and assignee.  Tasks take up full width for efficient vertical space usage.
- Assignee Page: Clicking on assignee name navigates to assignee's dedicated page showing all pending and completed tasks (view-only).
- User Profile Management: User profile page allows editing profile image, name, company name, company logo, password, and company address.

## Style Guidelines:

- Primary color: Calm Blue (#3498db) for a professional look.
- Secondary color: Light Gray (#ecf0f1) for backgrounds and subtle UI elements.
- Accent color: Green (#2ecc71) to indicate task completion and success.
- Use a clean and responsive layout, optimized for all devices. Prioritize vertical space to display more tasks.
- Consistent and simple icons for task status (pending, completed), edit, delete, and print actions.
- Subtle transitions for task completion and loading states.
